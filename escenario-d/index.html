Costo Acumulado y Pérdida del Poder Adquisitivo

Escenario D
Si una familia compra diariamente una canasta básica, el costo acumulado se representa como el área bajo la curva de precios: C = ∫ P(t) dt. Se comparan los tres métodos de integración para ver cuál es más preciso.

Problema Real

💸
Erosión del poder adquisitivo de las familias bolivianas durante la crisis. Con precios subiendo cada día, una familia que compra su canasta básica diariamente enfrenta un gasto total mensual que no es simplemente precio × días: la curva de precios cambia continuamente. El costo real acumulado es el área bajo esa curva de precios, es decir, una integral. Cuando el costo acumulado supera el ingreso mensual familiar, la familia entra en déficit. La integración numérica permite calcular ese costo total con precisión, comparar distintas trayectorias de precios (exponencial, cuadrática, con picos de pánico) y determinar en qué punto el gasto supera la capacidad económica del hogar.

Algoritmos Utilizados

Regla del Trapecio
Aproxima el área bajo la curva dividiendo el intervalo en n subintervalos y calculando el área de trapecios entre puntos consecutivos: ∫P dt ≈ h/2 · [P(t₀) + 2P(t₁) + … + 2P(tn-1) + P(tn)]. Error de orden O(h²). Simple y robusto, funciona bien con funciones suaves y es el punto de partida para métodos más sofisticados.
Simpson 1/3
Usa polinomios cuadráticos para aproximar la curva en cada par de subintervalos. Requiere n par: ∫P dt ≈ h/3 · [P₀ + 4P₁ + 2P₂ + 4P₃ + … + Pn]. Error de orden O(h⁴), notablemente más preciso que el trapecio con el mismo número de evaluaciones. Es el método estándar cuando la curva es suave.
Simpson 3/8
Variante de Simpson que usa polinomios cúbicos en grupos de 3 subintervalos. Requiere n múltiplo de 3: ∫P dt ≈ 3h/8 · [P₀ + 3P₁ + 3P₂ + 2P₃ + … + Pn]. Mismo orden de error O(h⁴) que Simpson 1/3, pero útil cuando el número de subintervalos disponible es múltiplo de 3, o para combinar con Simpson 1/3 en intervalos compuestos.
