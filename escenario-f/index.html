Rumores y Pánico en la Red de Distribución

Escenario F
Un pequeño cambio en la información (rumor) puede generar un gran cambio en la demanda. Se modela mediante un sistema lineal perturbado: Ax = b → A(x+δx) = b+δb. El número de condición κ(A) mide cuán sensible es el sistema a los rumores.

Problema Real

📡
Rumores y pánico: cómo la desinformación colapsa la red de distribución boliviana. Durante la crisis de carburante, un rumor —"se acabó el diésel en la zona norte", "van a subir los precios mañana"— desencadenaba colas masivas, compras de pánico y una demanda repentina que multiplicaba el consumo real por 2 o 3 veces en cuestión de horas. La red de distribución, modelada como un sistema lineal Ax = b, tiene una sensibilidad matemática a estas perturbaciones medida por el número de condición κ(A). Un sistema mal condicionado (κ alto) amplifica enormemente cualquier pequeño error o perturbación en los datos de demanda, haciendo que la solución —el plan de distribución— sea completamente diferente aunque el rumor haya sido mínimo.

Algoritmos Utilizados

Análisis de Perturbación Lineal
Dado el sistema Ax = b, si b se perturba en δb (el rumor), la nueva solución satisface A(x+δx) = b+δb. El error relativo está acotado por: ‖δx‖/‖x‖ ≤ κ(A)·‖δb‖/‖b‖, donde κ(A) = ‖A‖·‖A⁻¹‖. Este análisis cuantifica cuánto se amplifica el rumor en la solución final.
Número de Condición κ(A)
Mide la sensibilidad intrínseca del sistema. κ = 1 es perfectamente estable; κ = 10⁶ significa que un error del 0.0001% en los datos puede producir un error del 100% en la solución. Se calcula como κ(A) = ‖A‖·‖A⁻¹‖ (usando norma-2, la infinito o la de Frobenius). Un sistema mal condicionado requiere mayor precisión aritmética o reformulación del problema.
Resolución con Eliminación Gaussiana
El sistema original y el perturbado se resuelven ambos por eliminación gaussiana para obtener x y x+δx respectivamente. Comparando ambas soluciones se cuantifica el impacto real del rumor en cada variable de distribución: cuántas toneladas extra demanda cada zona por efecto del pánico.
