Umbrales Críticos de Abastecimiento

Escenario E
Se buscan raíces de funciones no lineales que representan: el punto donde el costo supera el ingreso familiar, la tasa de reposición crítica (consumo = llegada) y el umbral de opinión social (estabilidad ↔ masificación). Seleccioná la función y el método numérico.

Problema Real

🎯
Umbrales críticos en la crisis boliviana: ¿cuándo se cruza el límite? Muchos fenómenos de la crisis no son continuos sino que tienen puntos de quiebre: el día exacto en que el gasto familiar supera el ingreso mensual; la tasa mínima de reposición de carburante para que el sistema no colapse; el nivel de descontento social a partir del cual una protesta se masifica irreversiblemente. Todos estos son problemas de búsqueda de raíces: encontrar el valor x donde f(x) = 0. La función f mide el desequilibrio —déficit económico, déficit logístico, tensión social— y su raíz es el umbral crítico. Identificarlo con precisión permite actuar antes de que el sistema entre en crisis.

Algoritmos Utilizados

Bisección
Método garantizado si f(a)·f(b) < 0. Divide el intervalo [a,b] por la mitad en cada iteración y conserva el subintervalo donde f cambia de signo. Converge siempre, con error que se reduce a la mitad cada paso: error ≤ (b−a)/2n. Lento (convergencia lineal) pero absolutamente confiable. Ideal como primer diagnóstico para localizar el umbral crítico.
Newton-Raphson
Usa la tangente a la curva para saltar hacia la raíz: xn+1 = xn − f(xn)/f'(xn). Convergencia cuadrática cerca de la raíz (el número de dígitos correctos se duplica en cada iteración). Requiere calcular la derivada y una buena aproximación inicial. Puede diverger si f' ≈ 0 o si la función tiene comportamiento irregular.
Secante
Variante de Newton-Raphson que evita calcular f' usando una aproximación por diferencias finitas con dos puntos anteriores: xn+1 = xn − f(xn)·(xn−xn-1)/(f(xn)−f(xn-1)). Convergencia superlineal (orden ≈ 1.618, el número áureo). Útil cuando la derivada analítica no está disponible o es costosa de calcular.
