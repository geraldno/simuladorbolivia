Optimización de Abastecimiento y Red de Transporte

Escenario A
Se modela la distribución de carburante desde 3 plantas hacia 3 zonas (Norte, Centro, Sur). El sistema de ecuaciones representa el equilibrio entre oferta y demanda. Seleccioná el método y ajustá los parámetros.

Problema Real

⚡
Crisis de abastecimiento de carburante en Bolivia (2024–2025). Largas filas en surtidores, desabastecimiento regional y distribución desigual entre zonas del país pusieron en evidencia la fragilidad de la red logística nacional. Este escenario modela ese problema como un sistema de ecuaciones lineales: cada zona tiene una demanda fija y cada planta tiene una capacidad limitada. Encontrar cuánto debe enviar cada planta a cada zona —sin exceder su capacidad y satisfaciendo la demanda— es exactamente resolver el sistema Ax = b, donde A codifica las rutas, x son los flujos y b son las demandas. La solución óptima permite minimizar el desabastecimiento y distribuir equitativamente el carburante disponible.

Algoritmos Utilizados

Jacobi
Método iterativo que actualiza todas las variables simultáneamente usando los valores del paso anterior. En cada iteración k, calcula xi(k+1) = (bi − Σ aijxj(k)) / aii para todo j ≠ i. Converge si la matriz es diagonalmente dominante. Es sencillo de paralelizar pero más lento que Gauss-Seidel.
Gauss-Seidel
Variante de Jacobi que usa inmediatamente cada valor recién calculado. Al actualizar xi ya incorpora los x1…xi-1 del paso actual, lo que acelera la convergencia. Requiere aproximadamente la mitad de iteraciones que Jacobi en sistemas bien condicionados.
SOR (Sobre-relajación)
Extiende Gauss-Seidel con un factor de relajación ω ∈ (0, 2). Cada nueva estimación se combina con la anterior: xinew = (1−ω)xiold + ω·xiGS. Con ω óptimo (típicamente 1.2–1.8) la convergencia puede ser varias veces más rápida. ω = 1 equivale a Gauss-Seidel puro.
Descomposición LU
Método directo (no iterativo) que factoriza A = L·U, donde L es triangular inferior y U es triangular superior. Resuelve primero Ly = b (sustitución hacia adelante) y luego Ux = y (sustitución hacia atrás). Produce la solución exacta (salvo errores de redondeo) en un número fijo de operaciones O(n³). Ideal cuando se necesita resolver el mismo sistema con múltiples vectores b.
